# Kiro Log

A running record of where I got stuck and which Kiro feature got me unstuck. One row per problem. The Evidence column points to files or commits in this repository.

| Date | Problem | Kiro feature used | Result | Evidence |
|---|---|---|---|---|
| 2026-11-11 | Starting a data-heavy simulation alone. I needed every later session to follow the same rules (pure engine, cited parameters, political neutrality) without repeating them in each prompt. | **Steering**: generated from a written project brief. New requirements: a real policy track for the 5 tools, and a backtest against a real policy change with tolerances fixed before the result is computed. 4 new invariants added to the property tests. | Commit `905e473` (before) and the following commit (after); `git diff` on `.kiro/` |
