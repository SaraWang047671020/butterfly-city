4. 操作與無障礙

  • ☰ 是一個按鈕，名稱「選單」，有 aria-expanded；打開後焦點移到選單第一項，Esc 或 × 關閉，焦點回到 ☰。
  • 電腦版是右側面板（不擋城市）；手機版是全螢幕，焦點留在選單內，和其他對話框相同。
  • 選單裡任何一項打開對話框時，選單先關上，對話框關閉後焦點回到 ☰。
  • 政策列旁邊的狀態文字照舊（與真實相同／幾個區不同／需要處理），需要處理時 ☰ 上出現一個小點和文字提示「有一項政策需要處理」，不只靠顏色。
  • 新手引導改成：第 1 步指向 ☰（「政策都在這裡」），第 2 步指向選單裡的政策，之後照舊。
  • 減少動態時，面板直接出現，沒有滑動。觸控目標至少 44px。

5. 決定（2026-11-24 核准）

產品負責人核准本設計稿：「核准，A 留季度，B 可以」。A：手機版收起時在 ☰ 旁留季度。B：電腦版走路時「回到空中視角」放在季度旁邊。

A.手機版關閉時，要不要在 ☰ 旁邊留一個小小的季度（例如「2015 Q1」）？不留就是完全照你說的全部收起來；留的話不用打開選單就知道現在第幾季。 B.電腦版走路時，「回到空中視角」放在季度旁邊（1C）可以嗎？或也收進選單。

核准後我會更新 play-loop 規格（需求、設計、任務），再改程式，並用真實點擊在四種寬度與中英文檢查。
