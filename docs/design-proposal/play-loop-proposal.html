7. First_Play_Guide

第一次玩時，用一個亮色的提示框指著要按的地方，一共五步：政策卡、套用、下一季、Go there、城市報告。提示框只指路，不會幫你按。隨時可以按「Skip guide」跳過，之後也能從城市報告重看。

8. Dialog_Frame: one style for every window

所有視窗都用同一個外框：上方標題和關閉鈕、中間內容、下方一排按鈕（主要按鈕永遠在最右邊）。分三種大小：一般、大、全螢幕。手機上一律全螢幕。開新局、存檔、事件卡、Why? 都會換成這個樣式。

Start a new game?

Your current game stays in this browser until the new one replaces it. Export a save code first if you want to keep it.

The new game starts in 2015 Q1 with every policy on the real track, and asks who you are.

Sizes: md min(40rem, 100% − gutters), lg min(64rem, …), full. All modal dialogs open with showModal, so they always take clicks.
